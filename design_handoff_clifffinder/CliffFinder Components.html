Handoff notes

Component count: 34 reusable pieces. Foundations (5) + Buttons (5) + Inputs (7) + Navigation (4) + Surfaces (5) + Lists (4) + Indicators (7) + States (2).

Theming: all components react to two CSS custom properties — --accent (orange · green · blue) and body.dark. No component should hard-code colors outside of these tokens.

Type: three Google fonts. Poppins for titles & buttons. Inter for body. Montserrat for stat numbers. Avoid using these elsewhere.

Pin categories are semantic — orange, yellow, pink — and reused on category tags, the map legend, and any list filters. Don't substitute the accent color for these.

What's intentionally missing: onboarding (3-screen value prop) was scoped out. Edge-case states for unsafe-spot reports were also descoped.

Reference for hi-fi screens: CliffFinder Map.html · Wireframes: CliffFinder v2.html
